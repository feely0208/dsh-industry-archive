# 档案行业专项体检（dsh-industry-archive）

**什么时候用**：给档案馆/档案室、有归档义务的机关企事业单位做检查前自查，或梳理电子档案管理规范时。用户会提到「档案保存多少年」「电子档案怎么证明没被改」「销毁要不要审批」「系统迁移后怎么证明没丢」。

## 怎么用

```bash
<cli 路径> --root <项目目录>       # 检查一个项目
<cli 路径> --demo                  # 用内置样本看检出效果
<cli 路径> --list-rules            # 列出判据与出处
<cli 路径> --html archive.html     # 出 HTML 报告
```

## 它查什么

| 规则 | 查什么 |
|---|---|
| `ARC-RETENTION` | 档案保管期限：永久 / 定期 30 年、10 年 |
| `ARC-FOUR-PROPERTY` | 电子档案四性检测（真实性/完整性/可用性/安全性） |
| `ARC-DESTROY-APPROVAL` | 销毁审批与清册、监销记录 |
| `ARC-MIGRATION-TRACE` | 格式迁移/系统更换的校验和与验收留痕 |

每条判据都带法规名称与条款出处（档案法、DA/T 96-2022 等）与修复建议，报出时一并给出。
